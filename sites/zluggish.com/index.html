Zluggish

A self-hosted, open-source server for Zwift. Run it at home and ride any map, with your own ghosts, pacers and household riders.

Read the documentation Get the code on GitHub

What you get

Offline play
Ride with no connection to the Zwift servers.
Any map
Choose the world for each ride, on any day.
Your own ghosts
Ride against your previous efforts on the same route.
RoboPacers and pelotons
Build pacers from recorded rides, with a group of followers behind them.
Planned workouts
Get your Intervals.icu workouts in the launcher, and send finished rides back.
A web app for the household
Manage riders, activities, uploads and settings from a browser.

Zluggish is offline only. It does not connect to the public Zwift world, so official races, group rides and leaderboards are not available. Riders on the same Zluggish server can ride together.
