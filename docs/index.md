# Zluggish

Zluggish is an open-source server for riding in Zwift on your own network. Choose a world, ride with friends on the same server or race [ghosts from earlier rides](usage/features/ghosts.md). The [web app](usage/web-app.md) shows your activities and gives administrators tools to manage the server.

Your Zluggish progress is separate from the official Zwift service. Official events and global leaderboards are unavailable. You can use [integrations](usage/integrations/index.md) to upload activities or import workouts.

![An activity in the web app with a route map, elevation profile and ride statistics](../media/screenshots/webapp-activities.png)

## Get started

1. Check the [requirements](install/requirements.md).
2. [Install the server and create an administrator](install/server.md).
3. Set up Zwift on [Windows](install/clients/windows.md), [macOS](install/clients/macos.md), [Linux with Wine](install/clients/linux.md) or [Android](install/clients/android.md).

If you have an existing install of the legacy zwift-offline app, [back up and migrate your storage](maintenance/migrating.md) first.

Join the community on [Discord](https://discord.gg/GMdn8F8) or [Strava](https://www.strava.com/clubs/zoffline).
